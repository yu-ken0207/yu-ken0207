# Hi, I'm yu-ken0207 👋

[English](README.md) | **繁體中文**

我做「實際用得上的 AI 應用」：在自己電腦上跑的大型語言模型 App、AI Agent 與 MCP 工具、模型微調與部署、影像辨識。以下是可以公開的作品。

## 專長

- **LLM 應用**：地端模型（Ollama、LM Studio）、多個 AI 角色一起討論、長對話自動整理成摘要
- **AI Agent 與 MCP**：讓 AI 呼叫工具做事（先確認、可以復原）、MCP server 的驗證與稽核紀錄
- **模型微調與部署**：Llama 的 LoRA 微調、4-bit 量化、用 FastAPI 包成服務
- **電腦視覺**：YOLO 物件偵測、影片內容搜尋
- **App 與後端**：Expo / React Native（iPhone）、Go（跨平台桌面程式）、Python（FastAPI、Flask）
