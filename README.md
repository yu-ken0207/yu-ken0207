# Hi, I'm yu-ken0207 👋

**English** | [繁體中文](README.zh-TW.md)

I build practical AI applications: LLM apps that run on your own hardware, AI agents and MCP tools, model fine-tuning and serving, and computer vision. Below are the projects I can share publicly.

## What I work on

- **LLM apps**: local models (Ollama, LM Studio), several AI roles discussing together, long chats condensed into summaries automatically
- **AI agents and MCP**: AI that calls tools to get things done (you confirm first and can undo), MCP servers with authentication and audit logs
- **Fine-tuning and serving**: LoRA fine-tuning of Llama, 4-bit quantization, serving with FastAPI
- **Computer vision**: YOLO object detection, searching inside videos
- **Apps and backends**: Expo / React Native (iPhone), Go (cross-platform desktop), Python (FastAPI, Flask)
